# AdSense application checklist (StudyCue)

Use after Tier W-4 ships (10+ crawlable essays + legal pages).

1. Confirm canonical custom domain resolves with HTTPS; many teams wait ~4 weeks.
2. Verify `/privacy`, `/terms`, `/cookies`, `/help` render without auth.
3. Use manual placements only (`NEXT_PUBLIC_ADSENSE_*`); disable auto ads in AdSense UI.
4. Capture screenshots showing consent banner (accept vs reject ads cookies).
5. Submit with blog URLs listed in `/sitemap.xml`.
6. If rejected for thin content, expand two flagship posts before re-applying.
