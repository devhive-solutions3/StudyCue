# First 30 days: ad RPM tuning

1. Benchmark RPM weekly after AdSense fill stabilizes.
2. If RPM stays below USD 0.50 for two payout windows, evaluate Ezoic or other networks (keep consent CMP aligned).
3. Change one placement variable per sprint (slot size, sticky vs in-article).
4. Re-run Lighthouse when ad markup moves (CLS risk).
